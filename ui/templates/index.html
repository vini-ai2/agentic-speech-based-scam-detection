Analyze an audio file
Tips
  • Prefer WAV/MP3 files with clear speech.
  • If ASR is a stub, results may be limited locally.
  • Enable `AGENTIC_LLM_API_KEY` for LLM explanations.
Examples & Tips

Try uploading a short call recording. Example curl:

curl -X POST -F "audio=@call.wav" http://localhost:8501/api/analyze

Sample guidance:

  • Clear single-speaker samples produce better transcripts.
  • Use WAV or MP3 formats.
  • Enable the LLM API key for richer explanations.
Quick Demo

Use the API endpoint for programmatic access:

curl -X POST -F "audio=@call.wav" http://localhost:8501/api/analyze
Tool Status

ASR and acoustic tool selection is automatic from the repo; warnings will be shown in results.
